# Chiloba Mwabu - Personal Brand Platform

A production-ready, premium personal brand platform for Chiloba Mwabu - Professional Mathematics Educator, Career Consultant, MC, Gospel Music Director, and Lukwanga FM Radio Host.

## Features

- **Mathematics Resource Center** - Search, filter, and download educational resources
- **Smart Booking System** - Book tuition, MC services, consultations, and more
- **Career Assessment** - Interactive career guidance assessment
- **Student Dashboard** - Track downloads, bookmarks, and learning progress
- **Admin Dashboard** - Manage resources, bookings, messages, and testimonials
- **Gallery** - Photos and videos from teaching, events, ministry, and more
- **Testimonials** - Student, parent, school, and church testimonials
- **SEO Optimized** - Schema.org, Open Graph, Twitter Cards, sitemap
- **WCAG AA Accessible** - Keyboard navigation, ARIA labels, screen reader support
- **Dark Mode Default** - With light mode support
- **Responsive** - Desktop, tablet, and mobile

## Tech Stack

- **Frontend**: Next.js 14 (App Router), React 18, TypeScript
- **Styling**: Tailwind CSS, Framer Motion, GSAP
- **Backend**: Next.js API Routes
- **Database**: PostgreSQL (Supabase)
- **Auth**: Supabase Auth
- **Storage**: Supabase Storage
- **Charts**: Recharts
- **Forms**: React Hook Form, Zod
- **State**: TanStack Query
- **Notifications**: Sonner Toasts
- **Icons**: Lucide React

## Getting Started

1. Clone the repository
2. Copy `.env.local.example` to `.env.local` and fill in your values
3. Install dependencies: `npm install`
4. Run the dev server: `npm run dev`
5. Build for production: `npm run build`

## Deployment

Deploy to Vercel for the best experience:

```bash
npx vercel
```
